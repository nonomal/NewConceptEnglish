### 为什么迁移到 Releases

AnkiWeb 单个账户的可用同步空间有限。完整卡组包含大量图片、音频等媒体时，可能无法稳定上传、同步或更新。因此 Anki 继续作为本地制作与导出工具，成品 `.apkg` 改由 GitHub Releases 分发。卡组模板和发布说明维护在 [AnkiShare](https://github.com/andylee1890/AnkiShare) 项目中。
